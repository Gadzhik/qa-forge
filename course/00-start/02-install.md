## Что такое JDK, JRE и JVM

Компьютер не понимает Java напрямую. Происходит так:

1. Вы пишете код в файле `Hello.java` — это текст, понятный человеку.
2. **Компилятор** `javac` превращает его в **байт-код** — файл `Hello.class`. Это промежуточный язык, одинаковый для всех ОС.
3. **JVM** (Java Virtual Machine, «виртуальная машина Java») читает байт-код и выполняет его на вашем компьютере.

Поэтому Java-программа, собранная один раз, работает на Windows, macOS и Linux — нужна лишь JVM для каждой ОС. Это главная причина, почему наш курс одинаково работает везде.

- **JVM** — машина, которая выполняет байт-код.
- **JRE** (Java Runtime Environment) — JVM + стандартные библиотеки. Достаточно, чтобы **запускать** программы.
- **JDK** (Java Development Kit) — JRE + компилятор и инструменты. Нужен, чтобы **писать** программы. Нам нужен именно **JDK**.

**Почему версия 21?** Java выходит каждые полгода, но некоторые версии объявляются **LTS** (Long-Term Support — долгая поддержка): 8, 11, 17, 21, 25. Компании используют LTS. Версия 21 сейчас самая распространённая в вакансиях, и на ней собран весь курс. Более новая (например, 25) тоже подойдёт.

**Какой JDK качать?** Java — открытая технология, и JDK выпускают разные компании. Все они одинаково работают. Мы берём **Eclipse Temurin** (сборка от фонда Eclipse Adoptium) — бесплатная, без регистрации, для всех ОС.

## Шаг 1. Установка JDK 21

```tabs
Windows: |
  **Способ 1 — через winget (рекомендуется).** `winget` — встроенный в Windows 10/11 «магазин программ для командной строки».

  1. Нажмите **Win**, наберите `PowerShell`, откройте **Windows PowerShell**.
  2. Введите команду и нажмите Enter:

  ~~~powershell
  winget install EclipseAdoptium.Temurin.21.JDK
  ~~~

  - `winget` — программа-установщик;
  - `install` — команда «установить»;
  - `EclipseAdoptium.Temurin.21.JDK` — точное имя пакета: JDK 21 от Eclipse Adoptium.

  Если Windows спросит разрешение на изменения — согласитесь.

  **Способ 2 — вручную.** Откройте https://adoptium.net/temurin/releases/?version=21, выберите *Windows, x64, JDK, .msi*, скачайте и запустите. В установщике **обязательно включите** пункты *Set JAVA_HOME variable* и *Add to PATH* (нажмите на значок слева от пункта → «Will be installed on local hard drive»).

  3. **Закройте PowerShell и откройте заново** (новые настройки подхватываются только в новом окне) и проверьте:

  ~~~powershell
  java -version
  ~~~
macOS: |
  **Способ 1 — через Homebrew** (если он у вас есть). Homebrew — популярный менеджер пакетов для macOS.

  1. Откройте **Терминал** (Cmd+Пробел → «Терминал»).
  2. Выполните:

  ~~~bash
  brew install --cask temurin@21
  ~~~

  - `brew` — сам Homebrew;
  - `install` — «установить»;
  - `--cask` — ставим готовое приложение с установщиком (а не утилиту из исходников);
  - `temurin@21` — JDK Temurin версии 21.

  Нет Homebrew? Поставьте его командой с сайта https://brew.sh или используйте способ 2.

  **Способ 2 — вручную.** На https://adoptium.net/temurin/releases/?version=21 выберите *macOS*, архитектуру (**aarch64** для Mac на M1/M2/M3/M4, **x64** для Intel), тип *.pkg*. Скачайте и установите двойным кликом.

  3. Проверьте в **новом** окне терминала:

  ~~~bash
  java -version
  ~~~
Linux: |
  **Ubuntu / Debian / Mint:**

  ~~~bash
  sudo apt update
  sudo apt install -y openjdk-21-jdk
  ~~~

  - `sudo` — выполнить команду с правами администратора (спросит ваш пароль; символы при вводе не видны — это нормально);
  - `apt update` — обновить список доступных пакетов;
  - `apt install` — установить пакет;
  - `-y` — не спрашивать «Продолжить? [Y/n]», сразу отвечать «да»;
  - `openjdk-21-jdk` — JDK 21 (именно **jdk**, а не **jre**).

  **Fedora:** `sudo dnf install java-21-openjdk-devel` (`-devel` — это JDK, без него поставится только JRE).

  **Arch / Manjaro:** `sudo pacman -S jdk21-openjdk`.

  Проверка:

  ~~~bash
  java -version
  ~~~
```

Должно появиться примерно такое:

```text
openjdk version "21.0.5" 2024-10-15 LTS
OpenJDK Runtime Environment Temurin-21.0.5+11 (build 21.0.5+11-LTS)
OpenJDK 64-Bit Server VM Temurin-21.0.5+11 (build 21.0.5+11-LTS, mixed mode, sharing)
```

Главное — первая строка начинается с `21` (или больше). Остальные цифры у вас будут другими, это нормально.

Проверим заодно, что установлен именно **JDK** с компилятором:

```bash
javac -version
```

`javac` — Java-компилятор. Если команда отвечает `javac 21...` — всё отлично. Если «не найдена» — вы поставили JRE вместо JDK.

### Если `java` «не является внутренней или внешней командой» / «command not found»

Значит, система не знает, где лежит Java. Тут нужны два понятия.

**PATH** — это переменная окружения со списком папок, в которых система ищет программы. Когда вы набираете `java`, система по очереди заглядывает в каждую папку из PATH и ищет там файл `java` (в Windows — `java.exe`). Не нашла — пишет ошибку.

**JAVA_HOME** — переменная окружения, в которой записан путь к папке JDK. Её читают инструменты (Maven, Gradle, IDE), чтобы понять, какую Java использовать.

```tabs
Windows: |
  1. Узнайте, куда установился JDK. Обычно это `C:\Program Files\Eclipse Adoptium\jdk-21.x.x-hotspot`.
  2. Нажмите **Win**, наберите «переменные среды» → **Изменение системных переменных среды** → кнопка **Переменные среды**.
  3. В блоке «Системные переменные» нажмите **Создать**: имя `JAVA_HOME`, значение — путь из п.1.
  4. Найдите переменную `Path` → **Изменить** → **Создать** → впишите `%JAVA_HOME%\bin` → кнопкой **Вверх** поднимите строку наверх.
     - `%JAVA_HOME%` — подстановка значения переменной JAVA_HOME;
     - `\bin` — подпапка, где лежат `java.exe` и `javac.exe`.
  5. **OK** во всех окнах, откройте **новый** PowerShell и снова `java -version`.

  Проверить значения переменных можно так:

  ~~~powershell
  echo $env:JAVA_HOME
  ~~~

  `$env:` — так в PowerShell обращаются к переменным окружения.
macOS: |
  Установщик .pkg обычно всё настраивает сам. Если нет — добавьте в файл `~/.zshrc` строки:

  ~~~bash
  export JAVA_HOME=$(/usr/libexec/java_home -v 21)
  export PATH="$JAVA_HOME/bin:$PATH"
  ~~~

  - `~/.zshrc` — файл настроек оболочки zsh (стандартная в macOS), выполняется при открытии терминала;
  - `/usr/libexec/java_home -v 21` — встроенная утилита macOS, которая печатает путь к установленному JDK 21;
  - `$(...)` — подставить результат команды;
  - `export` — сделать переменную видимой для запускаемых программ;
  - `$JAVA_HOME/bin:$PATH` — новая папка **впереди** старого PATH (двоеточие разделяет папки).

  Открыть файл: `open -e ~/.zshrc`. После сохранения выполните `source ~/.zshrc` (перечитать настройки) или откройте новое окно.
Linux: |
  Пакетный менеджер настраивает `java` сам. Если установлено несколько версий, выберите нужную:

  ~~~bash
  sudo update-alternatives --config java
  ~~~

  Команда покажет список установленных Java и попросит ввести номер нужной.

  JAVA_HOME добавьте в `~/.bashrc` (или `~/.zshrc`, если у вас zsh):

  ~~~bash
  export JAVA_HOME=$(dirname $(dirname $(readlink -f $(which java))))
  ~~~

  Разбор изнутри наружу:
  - `which java` — где лежит команда java (например, `/usr/bin/java`);
  - `readlink -f` — это обычно ссылка; узнаём настоящий путь (`/usr/lib/jvm/java-21-openjdk/bin/java`);
  - `dirname` дважды — поднимаемся на два уровня вверх: из `.../bin/java` получаем `.../java-21-openjdk`.
```

## Шаг 2. Установка IntelliJ IDEA Community

**IDE** (Integrated Development Environment, «интегрированная среда разработки») — это редактор кода с суперсилами: подсвечивает ошибки, дописывает код, запускает тесты кнопкой, показывает отладчик. Для Java стандарт индустрии — **IntelliJ IDEA**. Версия **Community** бесплатная, и её хватает на весь курс.

```tabs
Windows: |
  ~~~powershell
  winget install JetBrains.IntelliJIDEA.Community
  ~~~

  Или скачайте установщик с https://www.jetbrains.com/idea/download/?section=windows (кнопка **Community Edition** ниже платной Ultimate). В установщике полезно отметить *Add "Open Folder as Project"* — появится пункт в контекстном меню папок.
macOS: |
  ~~~bash
  brew install --cask intellij-idea-ce
  ~~~

  `intellij-idea-ce` — Community Edition. Или скачайте .dmg с https://www.jetbrains.com/idea/download/?section=mac и перетащите в «Программы».
Linux: |
  Проще всего через **JetBrains Toolbox** (https://www.jetbrains.com/toolbox-app/) — он ставит и обновляет IDE. Или через snap:

  ~~~bash
  sudo snap install intellij-idea-community --classic
  ~~~

  - `snap` — универсальный менеджер пакетов (есть в Ubuntu из коробки);
  - `--classic` — разрешить программе полный доступ к файлам (IDE это нужно, чтобы открывать ваши проекты).
```

> 💡 IDEA поставит и свою Java — для работы самой IDE. Но для наших проектов используется JDK, который мы установили на шаге 1. Как его выбрать в IDEA — покажем в уроке 0.3.

## Шаг 3. Git

Git хранит историю изменений кода. Подробно разберём в модуле 2, а пока просто установим.

```tabs
Windows: |
  ~~~powershell
  winget install Git.Git
  ~~~

  Вместе с Git ставится **Git Bash** — терминал в стиле Linux. Он пригодится для команд из уроков про CI.
macOS: |
  ~~~bash
  xcode-select --install
  ~~~

  Команда ставит «инструменты командной строки» Apple, в которых есть Git. Или `brew install git`.
Linux: |
  ~~~bash
  sudo apt install -y git      # Ubuntu/Debian
  sudo dnf install -y git      # Fedora
  ~~~
```

Проверка: `git --version`.

## Шаг 4. Google Chrome

Нужен для UI-автотестов. Скачайте с https://www.google.com/chrome/ или:

```tabs
Windows: |
  ~~~powershell
  winget install Google.Chrome
  ~~~
macOS: |
  ~~~bash
  brew install --cask google-chrome
  ~~~
Linux: |
  Скачайте .deb (Ubuntu/Debian) или .rpm (Fedora) с https://www.google.com/chrome/ и установите двойным кликом. Подойдёт и Chromium из репозитория: `sudo apt install chromium-browser`.
```

> 💡 Драйвер браузера (chromedriver) **качать вручную не нужно**. Начиная с Selenium 4.6 его автоматически подбирает встроенный **Selenium Manager**. В старых статьях вы встретите ручную установку chromedriver — это больше не требуется.

Автоматизатор постоянно работает в **терминале** (его ещё называют консолью или командной строкой): запускает тесты, собирает проект, смотрит логи, работает с Git и Docker. Бояться его не нужно — это просто окно, в котором вы пишете команды текстом вместо того, чтобы нажимать кнопки мышкой.

## Какой терминал открыть

```tabs
Windows: |
  В Windows два стандартных терминала:

  - **PowerShell** — современный, **используйте его**. Нажмите Win → наберите `PowerShell` → Enter. В Windows 11 есть ещё приложение **Terminal**, внутри которого по умолчанию тот же PowerShell.
  - **cmd** (командная строка) — старый, с другими командами. В курсе он встречается только в файлах `start.cmd` и `stop.cmd`.

  Также после установки Git у вас есть **Git Bash** — терминал с командами как в Linux/macOS. Удобен, если хочется одинаковых команд везде.
macOS: |
  Приложение **Терминал**: Cmd+Пробел → «Терминал» → Enter. Внутри работает оболочка **zsh**.
Linux: |
  Обычно Ctrl+Alt+T или «Терминал» в меню приложений. Внутри — оболочка **bash** или **zsh**.
```

Терминал показывает **приглашение** (prompt) и ждёт команду. Например:

```text
PS C:\Users\anna>          ← Windows PowerShell
anna@MacBook ~ %           ← macOS zsh
anna@laptop:~$             ← Linux bash
```

В приглашении видно, **в какой папке вы сейчас находитесь** (`C:\Users\anna`, `~`). Знак `~` (тильда) — сокращение для вашей домашней папки.

## Как устроена команда

```text
команда   аргументы   опции
   │          │          │
  git      commit    -m "Первый коммит"
```

- **команда** — имя программы, которую нужно запустить (`git`, `java`, `ls`);
- **аргументы** — над чем работать (`commit`, имя файла);
- **опции (флаги)** — как работать. Обычно начинаются с `-` (короткие: `-m`) или `--` (длинные: `--version`).

Пробел разделяет части команды. Поэтому если в пути к файлу есть пробел, его берут в кавычки: `cd "My Documents"`.

## Главные команды

| Что сделать | Windows (PowerShell) | macOS / Linux |
|---|---|---|
| Где я? | `pwd` | `pwd` |
| Что в папке? | `ls` (или `dir`) | `ls`, подробно: `ls -la` |
| Перейти в папку | `cd путь` | `cd путь` |
| На уровень вверх | `cd ..` | `cd ..` |
| В домашнюю папку | `cd ~` | `cd ~` или просто `cd` |
| Создать папку | `mkdir имя` | `mkdir имя` |
| Показать файл | `cat файл` (или `type`) | `cat файл` |
| Удалить файл | `Remove-Item файл` (или `del`) | `rm файл` |
| Очистить экран | `cls` или `clear` | `clear` (или Ctrl+L) |
| Остановить программу | Ctrl+C | Ctrl+C |

> 💡 В PowerShell многие команды Linux работают как «псевдонимы» (`ls`, `cat`, `pwd`, `rm`), поэтому таблица почти одинаковая. Отличия начинаются в опциях: `ls -la` в PowerShell не сработает, там пишут `ls -Force`.

### Разбор по шагам

```bash
pwd
```

**pwd** = *print working directory* — «напечатать текущую папку». Отвечает полным путём, например `/Users/anna`.

```bash
ls -la
```

**ls** = *list* — показать содержимое папки. Опции:
- `-l` — подробный формат (права, размер, дата);
- `-a` — показать и **скрытые** файлы (их имена начинаются с точки, например `.git`, `.mvn`);
- `-la` — то же, что `-l -a`: однобуквенные опции можно склеивать.

```bash
cd Documents
cd ..
cd ~/Documents/projects
```

**cd** = *change directory* — перейти в папку.
- `cd Documents` — войти в папку `Documents` внутри текущей;
- `cd ..` — две точки означают «родительская папка», то есть подняться на уровень вверх;
- `cd ~/Documents/projects` — перейти по пути, начиная от домашней папки.

> 💡 **Tab — лучший друг.** Наберите первые буквы имени папки и нажмите Tab: терминал допишет остальное. Нажмите Tab дважды — покажет варианты. Это экономит время и спасает от опечаток.

> 💡 **Стрелка ↑** листает ранее введённые команды. Не надо набирать одно и то же заново.

## Пути: абсолютные и относительные

**Абсолютный путь** начинается от «корня» диска и однозначен из любого места:

- Windows: `C:\Users\anna\qa-course\start.cmd`
- macOS: `/Users/anna/qa-course/start.sh`
- Linux: `/home/anna/qa-course/start.sh`

**Относительный путь** отсчитывается от текущей папки:

- `start.sh` — файл в текущей папке;
- `./start.sh` — то же самое, `.` (одна точка) означает «текущая папка»;
- `../other` — папка `other` рядом с текущей;
- `exercises/m03-java-basics` — вложенная папка.

> ⚠️ **Разделители путей.** В Windows — обратная косая черта `\`, в macOS/Linux — прямая `/`. PowerShell понимает оба варианта, поэтому в курсе мы почти везде пишем `/`. А вот в Java-коде никогда не склеивайте пути через `"/"` вручную — для этого есть `Path.of(...)` (разберём в модуле 5), и тогда код работает на любой ОС.

## Запуск программ и скриптов

```tabs
Windows: |
  ~~~powershell
  .\mvnw.cmd -v
  ~~~

  - `.\` — «из текущей папки». PowerShell из соображений безопасности **не запускает** программы из текущей папки без явного `.\`;
  - `mvnw.cmd` — скрипт Maven Wrapper для Windows;
  - `-v` — опция «покажи версию».
macOS / Linux: |
  ~~~bash
  ./mvnw -v
  ~~~

  - `./` — «из текущей папки». Без этого оболочка искала бы `mvnw` только в папках из PATH и не нашла бы;
  - `mvnw` — скрипт Maven Wrapper;
  - `-v` — показать версию.

  Если пишет `Permission denied` — у файла нет права на запуск. Дайте его:

  ~~~bash
  chmod +x mvnw
  ~~~

  `chmod` = *change mode* (изменить права), `+x` = добавить право на выполнение (*execute*).
```

## Переменные окружения

Переменная окружения — это именованное значение, которое видят все программы, запущенные из терминала. Мы уже встречали `PATH` и `JAVA_HOME`.

```tabs
Windows: |
  ~~~powershell
  # Прочитать
  echo $env:PATH
  # Задать только для этого окна терминала
  $env:SHOP_URL = "http://localhost:8081"
  ~~~
macOS / Linux: |
  ~~~bash
  # Прочитать
  echo $PATH
  # Задать только для этого окна терминала
  export SHOP_URL=http://localhost:8081
  ~~~

  `export` делает переменную видимой для программ, которые вы запустите из этого терминала. Пробелов вокруг `=` быть не должно.
```

Знак `#` в начале строки — **комментарий**: терминал его игнорирует. В курсе мы пишем в комментариях пояснения прямо в командах.

> 🧪 **Попробуй сам.** Откройте терминал и выполните по очереди: `pwd`, `ls`, `cd ..`, `pwd`, `cd ~`, `mkdir qa-test`, `cd qa-test`, `pwd`. Посмотрите, как меняется текущая папка. Потом вернитесь: `cd ..` и удалите папку (`rmdir qa-test` в macOS/Linux, `Remove-Item qa-test` в PowerShell).

## Перенаправление вывода и конвейеры

Пригодится в модулях про логи и CI:

```bash
./mvnw test > build.log
```

`>` — записать всё, что команда печатает на экран, **в файл** `build.log` (файл перезаписывается). `>>` — дописать в конец файла.

```bash
cat logs/shop-app.out | grep ERROR
```

`|` (вертикальная черта, **pipe**, «труба») передаёт вывод первой команды на вход второй. `grep ERROR` оставляет только строки, содержащие слово ERROR. В PowerShell аналог `grep` — `Select-String`:

```powershell
Get-Content logs\shop-app.out | Select-String ERROR
```

## Типичные ошибки новичка

> ❌ **«command not found» / «не является внутренней или внешней командой».** Программа не установлена или её папки нет в PATH. Перечитайте урок 0.2.

> ❌ **«No such file or directory».** Вы не в той папке. Выполните `pwd` и `ls` и посмотрите, где вы и что рядом.

> ❌ **Программа «зависла».** Скорее всего, она просто работает (например, сервер ждёт запросы). Остановить — **Ctrl+C**.

> ❌ **Вставили команду с символом `$` или `>` из примера.** В документации иногда показывают приглашение: `$ ls`. Знак `$` набирать не нужно — это часть приглашения, а не команды.

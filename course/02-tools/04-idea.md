IDE — ваше основное рабочее место. Чем лучше вы её знаете, тем меньше времени уходит на рутину.

## Структура Maven-проекта в IDEA

Откройте в дереве **Project** модуль `exercises/m00-hello`:

```text
m00-hello/
├── pom.xml                      ← описание модуля для Maven
└── src/
    ├── main/java/               ← основной код (синяя папка)
    │   └── ru/qacourse/m00/Hello.java
    └── test/java/               ← тесты (зелёная папка)
        └── ru/qacourse/m00/HelloCheck.java
```

Цвет папок означает их роль: **синие** — исходный код, **зелёные** — тесты, **оранжевые/жёлтые** — `target` и прочие сгенерированные (их не трогают). Такую раскладку `src/main/java` и `src/test/java` называют **стандартной структурой Maven** — она одинакова во всех Java-проектах мира.

## Горячие клавиши, которые окупятся в первый же день

| Действие | Windows / Linux | macOS |
|---|---|---|

| Найти действие/настройку по названию | Ctrl+Shift+A | ⌘⇧A |
| Найти класс | Ctrl+N | ⌘O |
| Найти файл | Ctrl+Shift+N | ⌘⇧O |
| Поиск текста по всему проекту | Ctrl+Shift+F | ⌘⇧F |
| **Подсказка/исправление ошибки** (лампочка) | **Alt+Enter** | **⌥↩** |
| Автодополнение | Ctrl+Space | ⌃Space |
| Перейти к объявлению (куда ведёт имя) | Ctrl+B или Ctrl+клик | ⌘B или ⌘+клик |
| Назад к прошлому месту | Ctrl+Alt+← | ⌘[ |
| Переформатировать код | Ctrl+Alt+L | ⌘⌥L |
| Закомментировать строку | Ctrl+/ | ⌘/ |
| Дублировать строку | Ctrl+D | ⌘D |
| Удалить строку | Ctrl+Y | ⌘⌫ |
| Переименовать (везде в проекте) | Shift+F6 | ⇧F6 |
| Сгенерировать код (конструктор, геттеры) | Alt+Insert | ⌘N |
| Запустить текущее | Shift+F10 | ⌃R |

> 💡 Если запомнить только две комбинации, пусть это будут **Shift Shift** (найти всё) и **Alt+Enter** (IDEA, исправь это). Alt+Enter на красном подчёркивании предлагает варианты исправления: добавить импорт, создать метод, поправить тип.

## Живые шаблоны (Live Templates)

Наберите сокращение и нажмите Tab:

| Сокращение | Что вставит |
|---|---|
| `psvm` или `main` | `public static void main(String[] args) { }` |
| `sout` | `System.out.println();` |
| `fori` | цикл `for (int i = 0; i < ; i++)` |
| `iter` | цикл по коллекции `for (Тип x : коллекция)` |

## Запуск кода и тестов

- Зелёный ▶ слева от метода `main` или от теста → **Run**.
- ▶ рядом с именем тест-класса — запустить все тесты класса.
- Правый клик по папке `src/test/java` → **Run 'All Tests'**.

Результаты тестов появятся внизу: ✅ зелёные — прошли, ❌ красные — упали. Клик по упавшему тесту показывает ошибку и стектрейс; клик по синей ссылке в стектрейсе — переход к строке кода.

## Панель Maven

Справа вкладка **Maven**. Внутри — модули и их **Lifecycle** (жизненный цикл): `clean`, `compile`, `test`, `package`, `install`. Двойной клик по `test` = команда `mvn test` для модуля. Кнопка 🔄 **Reload All Maven Projects** — перечитать `pom.xml` после изменений (например, после добавления зависимости).

## Полезные плагины

**Settings → Plugins → Marketplace** (Ctrl+Alt+S / ⌘,):
- **Lombok** — уже встроен в новые версии; нужен для модуля 6;
- **Allure TestOps Support** или **Allure Report** — подсветка аннотаций Allure (модуль 14);
- **JSON To POJO** / **RoboPOJOGenerator** — генерация Java-классов из JSON (модуль 9);
- **Rainbow Brackets** — разноцветные скобки, проще читать вложенный код.

## Настройки для комфорта

- **Тема:** Settings → Appearance → Theme (светлая/тёмная).
- **Размер шрифта:** Settings → Editor → Font.
- **Автоимпорт:** Settings → Editor → General → Auto Import → включите *Add unambiguous imports on the fly* и *Optimize imports on the fly*. IDEA будет сама дописывать `import`.
- **Кодировка:** Settings → Editor → File Encodings → всё **UTF-8** (иначе русские буквы в Windows могут превратиться в «кракозябры»).

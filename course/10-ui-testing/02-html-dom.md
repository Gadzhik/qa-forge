Чтобы найти кнопку на странице, нужно понимать, как страница устроена.

## HTML

**HTML** — язык разметки страниц. Страница — это дерево **элементов** (тегов):

```html
<div class="product-card" data-testid="product-card" data-product-id="1">
    <h3>
        <a href="/product/1" class="product-name" data-testid="product-name">Классический бургер</a>
    </h3>
    <div class="price" data-testid="product-price">289.90 ₽</div>
    <form action="/cart/add" method="post">
        <input type="hidden" name="productId" value="1">
        <button type="submit" class="btn btn-add" id="add-1" data-testid="add-to-cart">В корзину</button>
    </form>
</div>
```

Анатомия элемента:

```text
<button type="submit" class="btn btn-add" id="add-1">В корзину</button>
 └─┬──┘ └────────────── атрибуты ────────────────┘ └───┬────┘ └──┬──┘
  тег                                                  текст   закрывающий тег
```

- **тег** — тип элемента;
- **атрибуты** — пары `имя="значение"`: настройки и метки элемента;
- **текст** — содержимое между открывающим и закрывающим тегами;
- элементы вкладываются друг в друга: `button` внутри `form` внутри `div`.

## Самые частые теги

| Тег | Что это |
|---|---|
| `div`, `span` | Контейнеры без смысла (блочный и строчный) |
| `h1`…`h6` | Заголовки |
| `p` | Абзац |
| `a href="..."` | Ссылка |
| `button` | Кнопка |
| `input type="text/password/email/number/checkbox/radio/file"` | Поля ввода |
| `select` + `option` | Выпадающий список |
| `textarea` | Многострочное поле |
| `form` | Форма (отправляет данные на сервер) |
| `label` | Подпись к полю |
| `table`, `tr`, `td`, `th` | Таблица, строка, ячейка, заголовок |
| `ul`/`ol` + `li` | Списки |
| `img` | Картинка |
| `iframe` | Встроенная другая страница |

## Важные атрибуты для тестов

| Атрибут | Зачем |
|---|---|
| `id` | Уникальный идентификатор на странице (должен быть уникальным, но не всегда так) |
| `class` | Классы для стилей (CSS). Может быть несколько через пробел: `class="btn btn-add"` |
| `name` | Имя поля формы — под ним значение уйдёт на сервер |
| **`data-testid`** (или `data-test`, `data-qa`) | **Специальная метка для автотестов**. Не используется для стилей и логики, поэтому не меняется при редизайне |
| `href` | Адрес ссылки |
| `type` | Тип поля/кнопки |
| `disabled`, `checked`, `hidden` | Состояние: неактивен, отмечен, скрыт |
| `aria-label`, `role` | Доступность для экранных читалок — тоже хорошие локаторы |

> 💡 **data-testid** — лучший друг автоматизатора. Если на вашем проекте их нет — попросите разработчиков добавлять (или добавьте сами в код фронтенда). Все важные элементы QA Burger их имеют.

## CSS

**CSS** задаёт внешний вид: цвета, размеры, расположение. Для тестов важны две вещи:
1. **CSS-селекторы** — язык, которым CSS выбирает элементы, — главный способ искать элементы в тестах (урок 10.3).
2. CSS может **скрыть** элемент (`display: none`, `visibility: hidden`) — элемент есть в HTML, но не виден. Selenium не даст кликнуть по невидимому элементу.

## DOM

Браузер, загрузив HTML, строит в памяти дерево объектов — **DOM** (Document Object Model). JavaScript страницы может менять DOM на лету: добавлять, удалять, скрывать элементы. Поэтому:
- то, что вы видите в DevTools → Elements, — **текущий DOM**, а не исходный HTML (исходный — Ctrl+U, «Просмотр кода страницы»);
- элемент может появиться через секунду после загрузки (подгрузился с сервера) — тест должен **подождать** (урок 10.5);
- элемент может быть **пересоздан** — старая ссылка на него станет недействительной (*stale element*, урок 10.5).

> 🧪 **Попробуй сам.** Откройте http://localhost:8081/playground/dynamic, DevTools → Elements. Нажмите «Загрузить» и смотрите, как в дереве у элемента `loaded` пропадает атрибут `hidden` через 3 секунды. Нажмите «Спрятать» — элемент `vanishing` исчезнет из дерева совсем.

## Формы

```html
<form action="/login" method="post">
    <input id="username" name="username">
    <input id="password" name="password" type="password">
    <button type="submit">Войти</button>
</form>
```

Нажатие на кнопку `type="submit"` (или Enter в поле) **отправляет форму**: браузер делает запрос на `action` методом `method` и **загружает новую страницу**. Для теста это означает: после клика вся страница заменяется, и элементы старой страницы больше недействительны.

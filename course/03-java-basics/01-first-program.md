## Что такое программа

**Программа** — это последовательность инструкций для компьютера. Компьютер выполняет их строго по порядку, буквально, без догадок. Если написать «положи в корзину 2 бургера», он положит ровно 2, даже если вы имели в виду 3.

Java — **компилируемый** язык со **строгой типизацией**:
- **компилируемый** — перед запуском код проверяется и переводится в байт-код компилятором `javac`. Многие ошибки находятся ещё до запуска;
- **строгая типизация** — у каждого значения есть тип (число, текст, да/нет), и смешивать их как попало нельзя.

## Hello, World — без IDE

Сделаем всё руками, чтобы понять, что на самом деле происходит, когда вы нажимаете ▶ в IDEA.

Создайте где-нибудь папку `java-hello` и в ней файл `Hello.java` (в любом текстовом редакторе, хоть в Блокноте):

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```

Теперь в терминале, в этой папке:

```bash
javac Hello.java
```

`javac` — компилятор. Он читает `Hello.java`, проверяет его и создаёт файл `Hello.class` с байт-кодом. Если в коде ошибка — напечатает её и `.class` не создаст.

```bash
java Hello
```

`java` — запуск JVM. Аргумент `Hello` — **имя класса** (не файла! без `.class`), в котором JVM найдёт метод `main` и начнёт выполнение. На экране появится `Привет, мир!`.

> 💡 Начиная с Java 11 можно запускать одним шагом: `java Hello.java` — JVM скомпилирует в памяти и сразу выполнит. Удобно для маленьких экспериментов.

> ⚠️ **Windows и русские буквы.** Если вместо «Привет» видны «кракозябры», выполните перед запуском `chcp 65001` (переключить консоль на UTF-8), а компилируйте с явной кодировкой: `javac -encoding UTF-8 Hello.java`.

## Разбор каждой строки

```java
public class Hello {
```

- `class Hello` — объявляем **класс** с именем `Hello`. В Java весь код живёт внутри классов. Пока считайте класс «контейнером» для кода; что это на самом деле, узнаем в модуле 4.
- `public` — **модификатор доступа**: класс виден всем. Правило Java: **публичный класс должен лежать в файле с таким же именем**. Класс `Hello` → файл `Hello.java`. Иначе ошибка компиляции.
- `{` — открывающая фигурная скобка начинает **тело** класса. Оно закончится парной `}` в последней строке.
- Имена классов принято писать **с большой буквы**, слова слитно, каждое с большой: `OrderService`, `CartTest`. Это стиль **PascalCase**.

```java
    public static void main(String[] args) {
```

Это **метод** `main` — точка входа программы. JVM ищет именно метод с такой «подписью» и начинает выполнение с него.
- `public` — метод доступен снаружи (JVM должна иметь возможность его вызвать);
- `static` — метод принадлежит классу, а не объекту; можно вызвать без создания объекта (подробно в модуле 4);
- `void` — метод ничего не возвращает (`void` — «пустота»);
- `main` — имя метода. Обязательно именно `main`;
- `(String[] args)` — **параметры** метода: массив строк, в который попадут аргументы командной строки (`java Hello раз два` → `args` = `["раз", "два"]`).

Запоминать наизусть не нужно — в IDEA есть шаблон: наберите `psvm` или `main` и Tab.

```java
        System.out.println("Привет, мир!");
```

Печать строки на экран (в «стандартный вывод»):
- `System` — встроенный класс Java для работы с системой;
- `.out` — его поле: стандартный поток вывода (консоль);
- `.println(...)` — метод «напечатать и перейти на новую строку» (*print line*). Есть ещё `print` — без перехода на новую строку;
- `"Привет, мир!"` — **строка** (текст). Строки в Java всегда в **двойных** кавычках;
- `;` — **точка с запятой** заканчивает каждую инструкцию. Забыть её — самая частая ошибка новичка.

Шаблон в IDEA: `sout` + Tab.

## Комментарии

Компилятор их игнорирует; они для людей.

```java
// Однострочный комментарий — до конца строки

/*
   Многострочный
   комментарий
*/

/**
 * Javadoc — документация к классу или методу.
 * IDEA показывает её во всплывающей подсказке (Ctrl+Q / F1 на macOS).
 */
```

Хороший комментарий объясняет **зачем**, а не **что**: «что» видно из кода.

## Ошибки компиляции: учимся читать

Удалите в `Hello.java` точку с запятой и выполните `javac Hello.java`:

```text
Hello.java:3: error: ';' expected
        System.out.println("Привет, мир!")
                                          ^
1 error
```

- `Hello.java:3` — файл и **номер строки**;
- `error: ';' expected` — что не так: «ожидалась `;`»;
- `^` — где именно компилятор споткнулся.

> 💡 **Читайте первую ошибку.** Одна пропущенная скобка может породить десяток сообщений ниже. Исправьте первую — и остальные часто исчезнут.

Ещё классика:

| Сообщение | Причина |
|---|---|
| `cannot find symbol` | Опечатка в имени или забыли объявить/импортировать |
| `class X is public, should be declared in a file named X.java` | Имя класса не совпадает с именем файла |
| `reached end of file while parsing` | Не хватает закрывающей `}` |
| `unclosed string literal` | Не закрыта кавычка `"` |
| `incompatible types` | Значение не того типа (модуль 3.2) |

## Пакеты

В заданиях курса вы видели первую строку:

```java
package ru.qacourse.m03;
```

**Пакет** — «папка» для классов, чтобы не было путаницы с одинаковыми именами. Пакет `ru.qacourse.m03` соответствует папке `ru/qacourse/m03/` внутри `src/main/java`. Принято называть пакеты как перевёрнутый домен компании: `ru.yandex...`, `com.google...`. Имена пакетов — строчными буквами.

## Как устроены задания модуля

В `exercises/m03-java-basics/src/main/java/ru/qacourse/m03/` лежат файлы `Task01Greeting.java`, `Task02Variables.java` и т.д. В каждом — несколько методов с заглушкой:

```java
public static String hello(String name) {
    throw new UnsupportedOperationException("TODO: напишите решение");
}
```

`throw new UnsupportedOperationException(...)` — «бросить исключение»: программа аварийно остановится с этим сообщением (подробно в модуле 5). Это заглушка: **удалите эту строку** и напишите решение вместо неё.

Методы пока устроены одинаково: `public static ТипРезультата имя(параметры)`. Метод получает значения (параметры), что-то вычисляет и **возвращает** результат командой `return`. Подробно — в уроке 3.9, а пока достаточно этого:

```java
public static String hello(String name) {
    return "Привет, " + name + "!";
}
```

- `String` перед именем — метод вернёт строку;
- `String name` — метод получает строку, внутри она доступна под именем `name`;
- `+` между строками — **склеивание** (конкатенация);
- `return` — вернуть результат тому, кто вызвал метод.

Чтобы попробовать метод руками, добавьте в класс `main` и вызовите его:

```java
public static void main(String[] args) {
    System.out.println(hello("Анна"));   // напечатает: Привет, Анна!
}
```

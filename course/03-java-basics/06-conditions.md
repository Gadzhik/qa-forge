Программа должна уметь выбирать: «если заказ от 1000 ₽ — доставка бесплатная, иначе платная». Для этого есть **условные операторы**.

## if

```java
if (orderAmount >= 1000) {
    System.out.println("Доставка бесплатно");
}
```

- `if` — «если»;
- в круглых скобках — **условие**, выражение типа `boolean`;
- в фигурных — **тело**: выполняется, только если условие `true`.

## if / else

```java
if (orderAmount >= 1000) {
    delivery = 0;
} else {
    delivery = 99;
}
```

`else` — «иначе»: выполняется, если условие `false`. Выполнится ровно одна из двух веток.

## Цепочка else if

```java
if (distanceKm < 0) {
    return -1;                       // некорректные данные
} else if (orderAmount >= 1000) {
    return 0;                        // бесплатно
} else {
    return 99 + 25 * distanceKm;     // платно
}
```

Условия проверяются **сверху вниз**, выполняется **первая** подходящая ветка, остальные пропускаются. Поэтому порядок важен: проверку некорректных данных ставим первой.

> ⚠️ **Всегда ставьте фигурные скобки**, даже для одной строки. Без них к `if` относится только следующая строка, и добавленная позже вторая строка будет выполняться всегда:
> ```java
> if (paid)
>     sendReceipt();
>     startCooking();   // выполнится ВСЕГДА, хотя отступ обманывает
> ```

## Ранний выход (guard clause)

Вместо глубокой вложенности удобно сразу «отсекать» особые случаи через `return`:

```java
public static int deliveryCost(int orderAmount, int distanceKm) {
    if (distanceKm < 0) return -1;
    if (orderAmount >= 1000) return 0;
    return 99 + 25 * distanceKm;
}
```

`return` сразу завершает метод, поэтому `else` уже не нужен. Код читается как список правил.

## Тернарный оператор

Короткая запись `if/else`, которая возвращает значение:

```java
String label = paid ? "Оплачен" : "Не оплачен";
int length = name == null ? 0 : name.length();
```

`условие ? значение_если_true : значение_если_false`. Хорош для простых случаев; для сложных — обычный `if`.

## switch

Когда сравниваем одно значение с несколькими вариантами. Современная форма (Java 14+), используем её:

```java
int percent = switch (code) {
    case "SALE10" -> 10;
    case "BURGER20" -> 20;
    default -> 0;
};
```

- `switch (code)` — что сравниваем;
- `case "SALE10" -> 10;` — если `code` равен `"SALE10"`, результат 10;
- `default` — для всех остальных значений;
- `switch` как выражение **возвращает значение**, поэтому его можно присвоить переменной или вернуть через `return`;
- `;` после закрывающей `}` — потому что это конец инструкции присваивания.

Несколько значений в одном `case`:

```java
String type = switch (category) {
    case "BURGER", "SIDE" -> "Еда";
    case "DRINK" -> "Напиток";
    default -> "Другое";
};
```

Если в ветке нужно несколько строк — блок с `yield`:

```java
int cost = switch (zone) {
    case "центр" -> 0;
    case "окраина" -> {
        int base = 99;
        yield base + 50;     // yield — «вернуть из этой ветки»
    }
    default -> 199;
};
```

> ⚠️ `switch` по строке с `null` бросит `NullPointerException`. Проверяйте `null` до `switch`.

### Старая форма switch

В старом коде и статьях встретите:

```java
switch (code) {
    case "SALE10":
        percent = 10;
        break;
    case "BURGER20":
        percent = 20;
        break;
    default:
        percent = 0;
}
```

Здесь обязателен `break` — без него выполнение «проваливается» в следующий `case`. Это источник багов, поэтому в новом коде используйте стрелки `->`.

## Связь с тест-дизайном

Каждая ветка условия — отдельный путь в программе. Чтобы проверить метод `deliveryCost`, нужен тест на **каждую** ветку: отрицательное расстояние, заказ от 1000, обычный заказ. И границу `1000` с соседом `999`. Так техника «таблица решений» из урока 1.6 превращается в набор тестов.

## Арифметические

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение (для строк — склеивание) | `5 + 3` | `8` |
| `-` | вычитание | `5 - 3` | `2` |
| `*` | умножение | `5 * 3` | `15` |
| `/` | деление (для целых — целочисленное!) | `7 / 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |

**Остаток `%`** удивительно полезен:
- `n % 2 == 0` — число чётное;
- `n % 10` — последняя цифра;
- `i % 3 == 0` — каждый третий.

Для отрицательных чисел остаток отрицательный: `-56 % 10` = `-6`. Взять модуль поможет `Math.abs(...)`.

## Сокращённые операторы

```java
int count = 5;
count += 3;   // то же, что count = count + 3   → 8
count -= 2;   // count = count - 2              → 6
count *= 2;   // count = count * 2              → 12
count /= 4;   // count = count / 4              → 3
count++;      // count = count + 1              → 4  (инкремент)
count--;      // count = count - 1              → 3  (декремент)
```

`++` и `--` бывают **постфиксными** (`count++`) и **префиксными** (`++count`). Разница видна только если использовать результат в том же выражении:

```java
int a = 5;
int b = a++;   // b = 5, потом a стало 6 (сначала отдать, потом увеличить)
int c = ++a;   // a стало 7, потом c = 7 (сначала увеличить, потом отдать)
```

> 💡 Совет: пишите `count++` отдельной строкой и не используйте его внутри других выражений — так код понятнее.

## Сравнения

Результат — `boolean` (`true` или `false`):

| Оператор | Значение |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `>` `<` | больше, меньше |
| `>=` `<=` | больше или равно, меньше или равно |

```java
int quantity = 100;
boolean tooMany = quantity > 99;    // true
```

> ⚠️ `=` — присваивание, `==` — сравнение. Перепутать — классика.

## Логические операторы

| Оператор | Название | Истина, когда |
|---|---|---|
| `&&` | И (AND) | **обе** части истинны |
| `\|\|` | ИЛИ (OR) | **хотя бы одна** истинна |
| `!` | НЕ (NOT) | переворачивает значение |

```java
boolean valid = quantity >= 1 && quantity <= 99;   // в диапазоне
boolean weekend = day == 6 || day == 7;
boolean notPaid = !paid;
```

**Короткое замыкание.** `&&` не вычисляет правую часть, если левая уже `false`; `||` — если левая уже `true`. Это используют для защиты от `null`:

```java
if (name != null && name.length() > 0) { ... }
```

Если `name == null`, правая часть не выполнится и NPE не будет. Поменяйте части местами — получите NPE.

## Приоритет

Как в математике: сначала `*`, `/`, `%`, потом `+`, `-`, потом сравнения, потом `&&`, потом `||`. Сомневаетесь — **ставьте скобки**, они делают код понятнее:

```java
boolean leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
```

Это правило високосного года: «делится на 4, но не на 100» **или** «делится на 400». Скобки показывают, что сначала проверяется первая пара условий.

## Класс Math

Полезные готовые функции:

```java
Math.abs(-5)        // 5      модуль
Math.max(3, 7)      // 7      максимум из двух
Math.min(3, 7)      // 3
Math.pow(2, 10)     // 1024.0 степень (результат double)
Math.sqrt(16)       // 4.0    квадратный корень
Math.round(2.5)     // 3      округление к ближайшему (long)
Math.floor(2.9)     // 2.0    округление вниз
Math.ceil(2.1)      // 3.0    округление вверх
```

## Связь с тестированием

Операторы сравнения и логики — основа проверки граничных значений. Метод из задания:

```java
public static boolean isValidQuantity(int quantity) {
    return quantity >= 1 && quantity <= 99;
}
```

Если разработчик напишет `quantity > 1` вместо `quantity >= 1`, значение 1 станет недопустимым. Именно поэтому в тесте мы проверяем **0, 1, 99, 100**, а не «какое-нибудь 50».

Строки — самый частый тип данных в автотестах: тексты на странице, JSON-ответы, сообщения об ошибках, URL, логи. Поэтому методы строк надо знать хорошо.

## Создание и склеивание

```java
String product = "Чизбургер";
String greeting = "Привет, " + "Анна" + "!";      // "Привет, Анна!"
String info = "Количество: " + 3;                  // "Количество: 3" — число превратилось в строку
String tricky = "Итого: " + 2 + 3;                 // "Итого: 23" !!
String fixed = "Итого: " + (2 + 3);                // "Итого: 5"
```

В строке `tricky` выражение вычисляется слева направо: `"Итого: " + 2` → `"Итого: 2"`, затем `+ 3` → `"Итого: 23"`. Скобки заставляют сначала сложить числа.

## Строки неизменяемы

Ни один метод не меняет исходную строку — он возвращает **новую**:

```java
String name = "  анна  ";
name.trim();                  // ❌ результат выброшен, name не изменилась
name = name.trim();           // ✅ сохранили новую строку в переменную
```

Это свойство называется **immutability** (неизменяемость) — частый вопрос на собеседовании.

## Главные методы

| Метод | Что делает | Пример | Результат |
|---|---|---|---|
| `length()` | длина | `"бургер".length()` | `6` |
| `charAt(i)` | символ по индексу (с 0!) | `"бургер".charAt(0)` | `'б'` |
| `substring(from)` | подстрока от индекса до конца | `"бургер".substring(3)` | `"гер"` |
| `substring(from, to)` | от `from` включительно до `to` **не** включительно | `"бургер".substring(1, 4)` | `"ург"` |
| `indexOf(s)` | позиция первого вхождения или -1 | `"бургер".indexOf("р")` | `2` |
| `contains(s)` | содержит ли | `"Классический бургер".contains("бургер")` | `true` |
| `startsWith(s)` / `endsWith(s)` | начинается / заканчивается | `"BUG-101".startsWith("BUG")` | `true` |
| `toUpperCase()` / `toLowerCase()` | регистр | `"sale10".toUpperCase()` | `"SALE10"` |
| `trim()` / `strip()` | убрать пробелы по краям | `"  QA ".trim()` | `"QA"` |
| `isEmpty()` | длина 0 | `"".isEmpty()` | `true` |
| `isBlank()` | пустая или только пробелы | `"   ".isBlank()` | `true` |
| `replace(a, b)` | заменить все вхождения | `"289.90".replace(".", ",")` | `"289,90"` |
| `split(regex)` | разбить на массив | `"a,b,c".split(",")` | `["a","b","c"]` |
| `equals(s)` | равны ли | `"QA".equals("qa")` | `false` |
| `equalsIgnoreCase(s)` | равны без учёта регистра | `"QA".equalsIgnoreCase("qa")` | `true` |
| `String.join(sep, ...)` | склеить через разделитель | `String.join(", ", "a", "b")` | `"a, b"` |
| `repeat(n)` | повторить | `"*".repeat(4)` | `"****"` |

> ⚠️ **Индексы начинаются с 0.** В строке `"бургер"` символ `б` имеет индекс 0, а последний `р` — индекс 5 (= length − 1). Обращение к `charAt(6)` вызовет `StringIndexOutOfBoundsException`.

Пример — маскирование карты:

```java
String card = "1234567812345678";
String masked = "**** **** **** " + card.substring(12);   // "**** **** **** 5678"
```

`substring(12)` — от символа с индексом 12 до конца, то есть последние 4 символа.

## Специальные символы (escape-последовательности)

Внутри строки обратная косая черта `\` начинает специальный символ:

| Запись | Что это |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\"` | двойная кавычка внутри строки |
| `\\` | сама обратная косая черта |

```java
String json = "{\"name\": \"Кола\"}";      // {"name": "Кола"}
String path = "C:\\Users\\anna";           // C:\Users\anna
```

## Текстовые блоки

Для многострочного текста (JSON, XML, SQL в тестах) с Java 15 есть **текстовые блоки** в тройных кавычках — без экранирования кавычек:

```java
String body = """
        {
          "username": "user",
          "password": "user123"
        }
        """;
```

Отступ слева, общий для всех строк, автоматически убирается. Мы будем часто использовать их в API-тестах.

## Форматирование

```java
String s = String.format("Заказ №%d на сумму %.2f ₽", 42, 489.9);
// "Заказ №42 на сумму 489,90 ₽" (разделитель зависит от языка системы!)
String s2 = "Заказ №%d, статус %s".formatted(42, "PAID");
```

- `%d` — целое число;
- `%.2f` — дробное с 2 знаками после запятой;
- `%s` — строка (или что угодно через `toString`).

> ⚠️ `%.2f` использует **региональные настройки** компьютера: в русской локали будет запятая (`489,90`), в английской — точка (`489.90`). Тест, сравнивающий такие строки, может проходить у вас и падать в CI. Задавайте локаль явно: `String.format(Locale.ROOT, "%.2f", 489.9)`.

## StringBuilder — когда склеиваем много

Так как строки неизменяемы, склеивание в цикле создаёт кучу промежуточных строк. Для этого есть `StringBuilder` — изменяемый «конструктор строк»:

```java
StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 3; i++) {
    sb.append("Строка ").append(i).append('\n');
}
String result = sb.toString();
```

- `new StringBuilder()` — создать пустой конструктор (о `new` — в модуле 4);
- `append(...)` — дописать в конец; возвращает тот же `sb`, поэтому вызовы можно цеплять;
- `toString()` — получить готовую строку.

Ещё полезное: `new StringBuilder("абв").reverse().toString()` → `"вба"`.

## Сравнение строк — ещё раз

```java
if (status.equals("PAID")) { ... }      // ⚠️ NPE, если status == null
if ("PAID".equals(status)) { ... }      // ✅ безопасно: литерал никогда не null
```

Приём «константа слева» защищает от `NullPointerException`.

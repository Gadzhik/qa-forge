**Цикл** — повторение действий. В автотестах циклы встречаются постоянно: пройти по всем товарам в ответе, по всем страницам каталога, повторить запрос, пока статус не станет READY.

## for

```java
for (int i = 1; i <= 5; i++) {
    System.out.println("Бургер №" + i);
}
```

Заголовок `for` состоит из трёх частей через `;`:

1. `int i = 1` — **инициализация**: выполняется один раз в начале. Объявляем **счётчик**;
2. `i <= 5` — **условие**: проверяется **перед** каждым повтором. Пока `true` — тело выполняется;
3. `i++` — **шаг**: выполняется **после** каждого повтора.

Порядок: `i = 1` → проверка `1 <= 5` ✓ → тело → `i++` (2) → проверка ✓ → тело → ... → `i++` (6) → проверка `6 <= 5` ✗ → выход.

Каждое выполнение тела называют **итерацией**. Счётчик `i` виден только внутри цикла.

Типичные варианты:

```java
for (int i = 0; i < 10; i++) { }       // 0..9 — 10 раз (стандарт для индексов массива)
for (int i = 10; i > 0; i--) { }       // обратный отсчёт 10..1
for (int i = 0; i < 100; i += 5) { }   // с шагом 5
```

> ⚠️ **Ошибка «на единицу» (off-by-one).** `i <= 10` против `i < 10` — разница в одну итерацию. Это ровно тот тип ошибки, который ловят граничные значения. Именно такая ошибка заложена в BUG-101 (пагинация теряет по элементу).

## Сумма в цикле — паттерн «аккумулятор»

```java
int sum = 0;                     // 1. до цикла — начальное значение
for (int i = 1; i <= n; i++) {
    sum += i;                    // 2. в цикле — накапливаем
}
return sum;                      // 3. после цикла — результат
```

Тот же паттерн для подсчёта (`count++`), произведения (начинаем с `1`!), поиска максимума.

## while

Повторяет, **пока** условие истинно. Используют, когда число повторов заранее неизвестно:

```java
int value = 12345;
int digits = 1;
while (value >= 10) {
    value /= 10;        // отбрасываем последнюю цифру
    digits++;
}
// digits = 5
```

Пошагово: 12345 → 1234 (2) → 123 (3) → 12 (4) → 1 (5) → `1 >= 10` ложно → выход.

> ⚠️ **Бесконечный цикл.** Если условие никогда не станет ложным, программа «зависнет». Например, забыли `value /= 10`. Останавливать — Ctrl+C или красный квадрат ■ в IDEA.

## do-while

Сначала выполняет тело, потом проверяет условие — тело выполнится **хотя бы раз**:

```java
int attempt = 0;
String status;
do {
    attempt++;
    status = getOrderStatus();      // спрашиваем сервер
} while (!status.equals("READY") && attempt < 10);
```

Это, кстати, ручная версия «подождать статус» — в модуле 13 мы заменим её на библиотеку Awaitility.

## for-each

Перебор всех элементов массива или коллекции без счётчика:

```java
double[] prices = {289.9, 99, 129};
for (double price : prices) {
    System.out.println(price);
}
```

Читается «для каждого `price` из `prices`». Используйте for-each, когда индекс не нужен — меньше шансов ошибиться на единицу.

## break и continue

```java
for (int i = 1; i <= 100; i++) {
    if (i % 2 == 0) continue;   // пропустить чётные: сразу к следующей итерации
    if (i > 9) break;           // выйти из цикла совсем
    System.out.println(i);      // 1 3 5 7 9
}
```

- `continue` — прервать текущую итерацию и перейти к следующей;
- `break` — выйти из цикла.

## Вложенные циклы

```java
for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 3; col++) {
        System.out.print(row * col + "\t");
    }
    System.out.println();
}
```

Внутренний цикл полностью проходит на **каждой** итерации внешнего: 3 × 3 = 9 выполнений тела.

## Что такое переменная

**Переменная** — именованная «коробка» в памяти, в которой лежит значение. У коробки есть **тип** — какие значения в неё можно класть.

```java
int quantity = 2;
```

- `int` — **тип**: целое число;
- `quantity` — **имя** переменной;
- `=` — **присваивание** (не «равно»!): положить значение справа в переменную слева;
- `2` — **значение**;
- `;` — конец инструкции.

Можно сначала объявить, а потом присвоить:

```java
int quantity;      // объявили: коробка есть, но пустая
quantity = 2;      // положили значение
quantity = 3;      // заменили значение — старое (2) пропало
```

> ⚠️ Переменную нельзя использовать, пока ей не присвоено значение: `int x; System.out.println(x);` — ошибка компиляции `variable x might not have been initialized`.

## Примитивные типы

В Java 8 **примитивных** типов — встроенных «простых» значений:

| Тип | Что хранит | Диапазон | Пример |
|---|---|---|---|
| `byte` | целое | −128 … 127 | `byte b = 10;` |
| `short` | целое | −32 768 … 32 767 | `short s = 1000;` |
| **`int`** | **целое** — используем по умолчанию | ≈ ±2,1 миллиарда | `int count = 42;` |
| **`long`** | большое целое | ≈ ±9,2·10¹⁸ | `long ms = 31_536_000_000L;` |
| `float` | дробное, малая точность | ~7 знаков | `float f = 1.5f;` |
| **`double`** | **дробное** — по умолчанию | ~15 знаков | `double price = 289.90;` |
| **`boolean`** | логическое | `true` / `false` | `boolean paid = false;` |
| `char` | один символ | символ Unicode | `char letter = 'А';` |

На практике чаще всего: `int`, `long`, `double`, `boolean`, `char`.

Детали записи:
- `31_536_000_000L` — суффикс `L` говорит «это long» (без него компилятор считает число `int` и ругается, что оно слишком большое). Подчёркивания `_` — просто для читаемости, компилятор их игнорирует;
- `1.5f` — суффикс `f` для `float`;
- `'А'` — символ в **одинарных** кавычках; строки — в двойных.

## Строки — не примитив

```java
String name = "Анна";
```

`String` пишется с большой буквы, потому что это **класс**, а не примитив. Строки — особая тема (урок 3.5), но использовать их можно уже сейчас.

## var — тип выводится сам

С Java 10 можно не писать тип, если он очевиден из значения:

```java
var quantity = 2;          // компилятор понял: int
var name = "Анна";         // String
```

Тип всё равно есть и не меняется: `quantity = "два";` — ошибка. `var` — только сокращение записи. В курсе мы чаще пишем тип явно, чтобы вы к ним привыкли.

## Константы: final

```java
final int MAX_QUANTITY = 99;
MAX_QUANTITY = 100;   // ошибка компиляции: cannot assign a value to final variable
```

`final` — значение присваивается один раз и больше не меняется. Константы принято называть `ЗАГЛАВНЫМИ_С_ПОДЧЁРКИВАНИЕМ`.

## Правила имён

- Можно: буквы, цифры, `_`, `$`. Нельзя начинать с цифры: `2price` — ошибка.
- Регистр важен: `price` и `Price` — разные переменные.
- Нельзя использовать ключевые слова: `int`, `class`, `public`...
- **Стиль camelCase**: первое слово с маленькой, следующие с большой: `orderTotal`, `isPaid`, `maxQuantity`.
- Имя должно объяснять смысл: `totalPrice`, а не `tp` или `x`. В автотестах хорошие имена делают тест читаемым как документацию.

> 💡 Технически можно писать имена по-русски (`int цена = 5;` скомпилируется), но так никто не делает — в индустрии код пишут английскими словами.

## Арифметика с переменными

```java
int hours = 24;
int minutes = 60;
int seconds = 60;
int secondsInDay = hours * minutes * seconds;   // 86400
```

Справа от `=` может быть любое **выражение**; сначала оно вычисляется, потом результат кладётся в переменную.

```java
int counter = 0;
counter = counter + 1;   // взять counter, прибавить 1, положить обратно → 1
```

Это не уравнение (которое было бы нерешаемым), а команда «новое значение = старое + 1».

## Переполнение

У `int` есть максимум — около 2,1 миллиарда (`Integer.MAX_VALUE` = 2 147 483 647). Если результат больше, он «переворачивается» в отрицательное число **без всякой ошибки**:

```java
int big = Integer.MAX_VALUE;
System.out.println(big + 1);   // -2147483648 !!!
```

```java
int msInYear = 365 * 24 * 60 * 60 * 1000;        // ❌ переполнение: 1471228928
long msInYear2 = 365L * 24 * 60 * 60 * 1000;     // ✅ 31536000000
```

Во втором случае `365L` — `long`, поэтому всё выражение считается в `long`. Если написать `long x = 365 * 24 * 60 * 60 * 1000;` — переполнение всё равно случится: выражение посчитается в `int` и только потом положится в `long`.

> 💡 Для тестировщика это источник багов: счётчики, суммы в копейках, миллисекунды. Хорошая проверка на граничные значения — очень большие числа.

## Деньги и double

```java
System.out.println(0.1 + 0.2);   // 0.30000000000000004
```

`double` хранит числа в двоичном виде, и многие десятичные дроби в нём представляются **неточно**. Для денег в реальных программах используют класс `BigDecimal` (он есть в QA Burger, вернёмся к нему в модуле 9). В заданиях модуля 3 используем `double`, а в тестах сравниваем с допуском (`isCloseTo(579.8, within(0.0001))`).

## Зоны видимости (scope)

Переменная живёт только внутри **блока** `{ ... }`, где объявлена:

```java
public static void main(String[] args) {
    int a = 1;
    if (a > 0) {
        int b = 2;                  // b живёт только внутри этих фигурных скобок
        System.out.println(a + b);  // ✅ видны и a, и b
    }
    System.out.println(b);          // ❌ ошибка: cannot find symbol b
}
```

Правило: переменная видна от места объявления до закрывающей `}` своего блока, включая вложенные блоки. Объявлять переменные стоит как можно ближе к месту использования и в как можно меньшей области.

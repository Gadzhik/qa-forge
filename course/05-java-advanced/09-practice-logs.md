Этот урок — практический: соберём всё изученное (коллекции, стримы, исключения, файлы) в одну задачу из жизни автоматизатора — **отчёт по логу** приложения. Попутно — два новых инструмента: `Random` и регулярные выражения.

## Random — случайные данные

Тестовые данные часто генерируют случайно: имя пользователя, email, количество. Так тесты не мешают друг другу (например, при регистрации уникального email).

```java
Random random = new Random();
int quantity = random.nextInt(99) + 1;       // от 1 до 99
double coin = random.nextDouble();           // [0.0, 1.0)
boolean flag = random.nextBoolean();
String email = "user" + random.nextInt(1_000_000) + "@test.local";
```

- `nextInt(n)` — от 0 до n−1 (**n не включается**!). Отсюда `+ 1`, чтобы получить 1..99;
- новые версии Java: `random.nextInt(1, 100)` — от 1 включительно до 100 не включительно.

```java
List<String> menu = List.of("Кола", "Фри", "Бургер");
String randomItem = menu.get(random.nextInt(menu.size()));
```

Для уникальных строк удобен `UUID.randomUUID().toString()` → `"3f2b6c1e-..."`.

> 💡 **Воспроизводимость.** `new Random(42)` — «зерно» (seed) 42: последовательность чисел всегда одна и та же. Если тест со случайными данными упал, а данные не залогированы, повторить его невозможно. Правило: **логируйте случайные данные**, которые использует тест (в модуле 14 — прикладывайте их в отчёт Allure). В модуле 9 мы возьмём библиотеку **Datafaker** — она генерирует правдоподобные имена, адреса, телефоны.

## Регулярные выражения

**Регулярное выражение** (regex) — шаблон для поиска текста. Нужны, чтобы вытащить из строки части: номер заказа из сообщения, сумму из лога, код из письма.

Основы синтаксиса:

| Шаблон | Значение | Пример совпадения |
|---|---|---|
| `abc` | ровно «abc» | abc |
| `.` | любой символ | a, 1, % |
| `\d` | цифра | 7 |
| `\w` | буква/цифра/_ (латиница) | a, Z, 5, _ |
| `\s` | пробельный символ | пробел, таб |
| `\S` | не пробельный | a, 1, . |
| `[abc]` | один из символов | b |
| `[^]]` | любой, кроме `]` | a |
| `X*` | X ноль или более раз | |
| `X+` | X один или более раз | ddd |
| `X?` | X ноль или один раз | |
| `X{3}` | ровно 3 раза | |
| `^` / `$` | начало / конец строки | |
| `(...)` | **группа** — часть, которую можно достать | |

Пример — строка лога QA Burger:

```text
2024-05-12T12:01:15Z INFO [http-1] OrderService - order created id=1 user=user total=521.82
```

Шаблон для «order created»:

```text
order created id=(\d+) user=(\S+) total=([\d.]+)
```

- `id=(\d+)` — после `id=` одна или больше цифр — **группа 1**;
- `user=(\S+)` — после `user=` не-пробельные символы — **группа 2**;
- `total=([\d.]+)` — цифры и точки — **группа 3**.

В Java:

```java
Pattern ORDER = Pattern.compile("order created id=(\\d+) user=(\\S+) total=([\\d.]+)");

Matcher m = ORDER.matcher(line);
if (m.find()) {
    String user = m.group(2);                       // "user"
    double total = Double.parseDouble(m.group(3));  // 521.82
}
```

> ⚠️ **Двойные обратные слеши.** В строке Java `\` — служебный символ (урок 3.5), поэтому regex `\d` пишется как `"\\d"`. В текстовом блоке `"""` — тоже `\\d`.

- `Pattern.compile(...)` — скомпилировать шаблон (делают один раз, в `static final` поле);
- `matcher(text)` — «сопоставитель» для конкретной строки;
- `find()` — найти **где-нибудь** в строке; `matches()` — строка **целиком** должна подходить;
- `group(n)` — текст n-й группы; `group(0)` — всё совпадение.

Проверить regex удобно на https://regex101.com (выберите Flavor: Java).

Простые случаи без Pattern:

```java
"BUG-101".matches("BUG-\\d{3}");           // true — строка целиком соответствует
"a, b,c".split(",\\s*");                   // ["a", "b", "c"] — разбить по запятой и пробелам
"Заказ №42".replaceAll("\\D", "");         // "42" — убрать всё, кроме цифр
```

## Задача: отчёт по логу

Представьте: ночью упало 20 автотестов, у вас есть лог QA Burger. Нужно быстро понять: сколько ошибок, какие, сколько заказов прошло. Именно это и делает класс `Task09LogReport`.

Метод `parse` уже написан — разберите его:

```java
private static final Pattern LINE = Pattern.compile("^\\S+ (\\w+) \\[[^]]+] (\\S+) - (.*)$");
```

- `^\S+` — с начала строки: время (без пробелов);
- ` (\w+)` — пробел и **уровень** (INFO/WARN/ERROR) — группа 1;
- ` \[[^]]+]` — пробел и имя потока в квадратных скобках (`\[` — сама скобка, `[^]]+` — всё, кроме закрывающей скобки);
- ` (\S+)` — **логгер** — группа 2;
- ` - (.*)$` — дефис и **сообщение** до конца строки — группа 3.

Вам осталось написать три метода отчёта — это `groupingBy`, `filter` + `map` и regex + `groupingBy` со `summingDouble`.

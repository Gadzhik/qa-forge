Песочница

Страницы для отработки приёмов UI-автоматизации. У каждого интересного элемента есть id и data-testid.

  • Формы: поля, чекбоксы, радио, выпадающие списки
  • Alert, Confirm, Prompt
  • Basic Auth (admin / admin)
  • Iframe
  • Drag & Drop
  • Наведение мыши, двойной и правый клик
  • Динамические элементы и ожидания
  • Таблица с сортировкой
  • Загрузка файла
  • Скачивание файлов (TXT, PDF, XLSX)
  • Новые вкладки и окна
  • Бесконечная прокрутка
  • Модальное окно
